Miniproject📌 : web stock predict (lstm)
===

## ภาพรวม
เว็ปที่ใช้ Flask ในการเเสดงการทำนายราคาหุ้นโดยใช้โมเดล Deep Learning (lstm)โดนดึงข้อมูลหุ้นย้อนหลังจาก Yahoo Finance และ ใช้โมเดล LSTM เพื่อพยากรณ์ราคาหุ้นและแสดงผลลัพธ์ด้วย Matplotlib

## คุณสมบัติ
- ดึงข้อมูลหุ้นจาก Yahoo Finance
- แสดงเส้น EMA (20,50,100)
- ใช้โมเดล LSTM ในการช่วยในการคาดการณ์
- ให้ผู้ใช้ป้อนสัญลักษณ์หุ้นผ่านเว็บอินเทอร์เฟซ
- สามารถดาวโหลดข้อมูล csv ได้

## การติดตั้ง

```sh
pip install numpy pandas matplotlib flask keras tensorflow yfinance scikit-learn
```

## วิธีใช้งาน
1. โคลนโปรเจกต์
2. โดยโมเดลที่ต้องการใช้ในการทำนายคือ LSTM (`stock_dl_model.h5`) เเละต้องอยู่ในไดเรกทอรีที่ถูกต้อง
3. รันแอปพลิเคชัน Flask:

```sh
python app.py
```

4. เปิดเบราว์เซอร์และไปที่ `http://127.0.0.1:5000/`
5. ป้อนสัญลักษณ์หุ้น เช่น `AAPL`, `TSLA`, `NVDA` และกดส่ง
6. ดูข้อมูลหุ้น ผลการพยากรณ์ และดาวน์โหลดไฟล์ CSV

## โครงสร้างไฟล์
- `app.py` - ไฟล์หลักของแอปพลิเคชัน Flask
- `templates/index.html` - HTML
- `static/` - เก็บข้อมูลหุ้นเเละ กราฟเเสดงผลจากmatplotlib

## รายละเอียดของโมเดล
โมเดล LSTM ถูกฝึกให้พยากรณ์ราคาหุ้นโดยใช้ข้อมูลย้อนหลังเพื่อปรับคาparamiterต่างๆเพื่อให้ได้ราคาเป้าหมายนั้นวันต่อไปเเละใช้ข้อมูลราคาปิดย้อนหลัง 100 วันเป็นอินพุต และคาดการณ์ราคาล่วงหน้า 30 วัน 

## การพัฒนาในอนาคต
- เพิ่มโมเดล Machine Learning อื่นๆเพื่อเพิ่มความแม่นยำ
- อยากพัฒนาระบบในใช้ผลประกอบ การรายปีเเละรายไตรมาส ในการตัดสินใจ
- ในตอนเเรกจะทำการเพิ่มข้อมูลของ10q,10k ซึ่งคือข้อมูลรายปีเเละไตรมาสในการช่วยเรื่องตัดสินพร้อมกับตารางความรู้สึกของนักลงทุนต่อหุ้นนั้นๆ
